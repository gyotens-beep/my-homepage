# 健康教室てんびより ホームページ

岡山市南区を中心に活動する理学療法士による健康寿命の伴走サービス「健康教室てんびより」の公式ホームページです。
HTML と CSS だけで作られているので、ビルド不要でそのまま公開できます。

## ファイル構成

- `index.html` — ページ本体（ヒーロー / お悩み / 行天メソッド / ご利用の流れ / 運営者 / お問い合わせ）
- `style.css` — スタイル（ブランドカラー対応、スマホ対応）
- `CLAUDE.md` — ブランドガイドラインとライティングルール

## カスタマイズ方法

1. 文章の修正は `index.html` を直接編集する
2. 色を変えたい場合は `style.css` の先頭にある `:root` の変数（`--teal` / `--amber` など）を編集する
3. 料金やプログラム内容が確定したら「（予定）」の表記を更新する

## 公開方法（GitHub Pages）

1. GitHub のリポジトリページで **Settings → Pages** を開く
2. Source を「Deploy from a branch」にして、ブランチ（例: `main`）と `/ (root)` を選択して保存
3. 数分後に `https://<ユーザー名>.github.io/my-homepage/` で公開されます
